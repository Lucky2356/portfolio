# Портфолио Alex

Сайт-портфолио в виде рабочего стола вымышленной ОС: проекты — иконки на столе,
их можно открывать в окнах и перетаскивать. Ниже по прокрутке — манифест,
изометрическая 3D-сцена рабочего места (ноутбук и два телефона с живым кодом на
экранах, нарисованная кодом на canvas, без видео и без библиотек) и контакты.
Отдельными страницами открываются «Работы», «Обо мне» и «Контакты».

Девять проектов подтянуты из публичных репозиториев
[github.com/Lucky2356](https://github.com/Lucky2356) — со скриншотами, задачей,
решением, результатом и метрикой у каждого.

## Что где лежит

| Путь | Что это |
|---|---|
| `Main.dc.html` | Главный артборд: вся вёрстка, стили, 3D-движок и данные проектов. Скриншоты приложений встроены в него как data-URI. |
| `Work.dc.html`, `About.dc.html`, `Contact.dc.html` | Остальные артборды дизайн-канваса. |
| `canvas.json` | Раскладка артбордов на канвасе. |
| `scripts/build-site.mjs` | Сборка: раскрывает шаблоны и превращает артборд в обычную HTML-страницу. |
| `portfolio-dev.html` | Готовый дизайн-канвас со всеми четырьмя артбордами. Пересобирается только инструментом Claude Design, поэтому лежит в репозитории целиком. |
| `.github/workflows/deploy.yml` | Сборка на GitHub Actions и публикация на GitHub Pages. |

Сборка (`dist/`) в репозитории не хранится — её делает CI при каждом пуше.

## Сборка

Нужен только Node.js 20+, зависимостей нет.

```bash
npm run build
```

Появится `dist/index.html` — самодостаточная страница со всеми стилями,
скриптами и картинками внутри. Открывается двойным кликом, сервер не нужен.

`dist/portfolio-site.html` — тот же сайт без `<!doctype>`, `<html>` и `<body>`,
для публикации артефактом.

## Публикация на GitHub Pages

Сборка идёт при каждом пуше в `main`. Публикация выключена, пока не сделано два шага:

1. **Settings → Pages → Source: GitHub Actions**
2. **Settings → Secrets and variables → Actions → Variables → New variable:**
   `DEPLOY_PAGES` = `true`

После этого сайт будет обновляться сам на `https://lucky2356.github.io/portfolio/`.
Чтобы снова снять его с публикации, достаточно поменять переменную на `false`.
